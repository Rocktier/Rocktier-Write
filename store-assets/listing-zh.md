# Rocktier Write — 商店文案（中文，第二语言；母版为英文）

**简短描述**
为长篇小说与长篇写作而生的专注写作应用：章节、专注模式、DOCX/PDF 导出，100% 离线。

**详细描述**

Rocktier Write 为"长的东西"而生——小说、回忆录、学位论文、剧本——以"章"计量、而非以"条"计量的工作。它完整运行于你的 Windows 电脑：无账号、无云端、无任何网络连接。

**为什么离线是最安全的选择。** 书稿是不可替代的。从你的草稿存进别人服务器的那一刻起，它的安全就取决于对方的安全性、备份、隐私政策——以及这家公司的未来。Rocktier Write 把每个字都留在你的机器上：没有可被攻破的服务器，没有可泄露的账号，没有需要信任的第三方。你的作品只存在于一个地方——你选择的地方——除非你主动把它放到别处。对于输不起的写作，离线不是限制，而是现有架构中最安全的一种。

**为章节而生。** 章节侧栏列出每个标题，附分章字数与目标进度，书的全局一目了然。可设定本次写作目标并实时跟踪；多文档标签让多个草稿同时打开。

**专注模式。** 专注模式把除当前段落（或单个句子）之外的一切淡出，打字机滚动让视线留在文字上，而不是窗口上。

**从初稿到交稿。** 用干净的 Markdown 写作并实时预览，然后导出出版社要的格式：.docx、PDF 或纯文本——全部在本机渲染完成。已有的 Word 文档也可以导回 Markdown。查找替换、字数目标与深色主题，陪你到底。

**你的文件，普通的文件。** 一切都是你掌控的文件夹里的 .md 纯文本。任何时候都能用任何编辑器打开——哪怕这款应用明天就消失。换行符原样保留，崩溃恢复连从未保存到磁盘的文档也能找回。

**小巧，且隐私由架构保证。** 安装包约 3 MB——是完整应用本身，不是下载器。无遥测、无统计、无账号、无自动更新。应用包未声明任何网络能力：想联网也做不到。

八种界面语言：英语、简体中文、日语、韩语、法语、德语、西班牙语、葡萄牙语。永久完全离线。

**要点**
- 格式：Markdown（.md）进出；.docx、PDF、纯文本导出；.docx 导入
- 章节侧栏：分章字数与目标
- 专注模式（段落/句子淡出）与打字机滚动
- 多文档标签、查找替换、深色主题
- 8 种界面语言
- 永久完全离线
