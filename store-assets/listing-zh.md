# Rocktier Write — 商店文案（中文，译自英文母版）

**简短描述**
为长篇写作而生的无干扰写作应用。一切都在你的机器上完成 —— 无账号、无云端、无同步，书稿永不离开你的设备。

**详细描述**

写长的东西。小说、回忆录、学位论文 —— Rocktier Write 为以"章"计量的工作而生。

**隐私是架构，不是承诺。** Rocktier Write 100% 离线运行：没有要注册的账号，没有要同步的云端，没有回传的遥测。书稿以纯 Markdown 文件保存在你自己控制的文件夹里，除非你主动拷贝，它永远不会离开这台机器。对写作者而言，这不是功能清单上的一条 —— 这是自由写作的前提。

**为章节而生。** 章节侧栏追踪每个标题，附分章字数与目标进度；专注模式把除当前段落（或句子）之外的一切淡出；打字机滚动让视线始终停在字上。

**从初稿到交稿。** 用干净的 Markdown 写作，实时预览，然后交出出版社要的格式 —— Word（.docx）、PDF 或纯文本，全部在本机渲染完成。

**要点**
- 格式：Markdown 进出；Word（.docx）与 PDF 导出
- 字数目标 + 分章进度
- 8 种界面语言
- 永久完全离线
